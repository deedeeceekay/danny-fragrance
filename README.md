# Fragrance & Cosmetics Store: static mockup

Static HTML version of the store design (homepage, five product pages, search and contact). The homepage switches to a dedicated phone layout below 750px wide. No build step and no dependencies.

## Run locally
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Publish on GitHub Pages
1. Push this folder to a repo.
2. Settings > Pages > Deploy from branch > `main` / root.

## Pages
- `index.html`: homepage
- `product-khamrah-qahwa.html`, `product-royal-taboo.html`, `product-coconut-hair-mask.html`, `product-aloe-vera-body-wash.html`, `product-skin-food.html`
- `search.html`, `contact.html`

## Before launch
- Reviews, the review count and "1000+ satisfied customers" are placeholders. Replace them with real figures.
- Fill in the footer company name, number, address and contact email.
- Policy links (Shipping, Returns, Privacy, Terms) point nowhere yet.
- Some product image tiles are placeholders.

Fonts: Hanken Grotesk and Space Mono via Google Fonts.
